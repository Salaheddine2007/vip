Wat is https iptv org github io iptv index m3u?

De tekst https iptv org github io iptv index m3u is een webadres dat naar de index van het iptv-org-project wijst. Dat project verzamelt links naar openbare livestreams van zenders die zelf gratis via internet worden aangeboden. De lijst wordt door de community bijgewerkt, waardoor zenders regelmatig verdwijnen of een nieuw adres krijgen.

Hoe is de lijst opgebouwd?

De index bevat één groot M3U-bestand, maar ook deellijsten per land, taal en categorie. Wie zoekt naar https iptv org github io iptv index m3u vindt dus een brede mix van nieuws, muziek en regionale zenders, zonder gegarandeerde kwaliteit.

Wat zit er niet in?

Betaalde sportpakketten, streamingdiensten en de meeste commerciële Nederlandse zenders zijn niet legaal gratis verkrijgbaar en staan dus niet in https iptv org github io iptv index m3u. Verwacht daarom geen complete Eredivisie of Netflix-achtig aanbod.
